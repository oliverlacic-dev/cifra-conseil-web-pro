# Thème Odoo — Cifra Conseils

Module de thème Odoo Website ciblant Odoo 19. Il reprend l'identité Cifra Conseils, les pages Accueil/Services/À propos/Contact, les services incluant l'implantation Odoo et le formulaire Contact vers `crm.lead`.

## Installation

1. Copier le dossier `odoo_cifra_conseils` dans un répertoire inclus dans `addons_path`.
2. Redémarrer Odoo et activer le mode développeur.
3. Mettre à jour la liste des applications.
4. Installer **Cifra Conseils Website Theme**.
5. Définir la page d'accueil et ajuster le menu depuis Website > Configuration > Menus.

Le site React reste la version de référence dans ce projet; ce dossier est le paquet portable à importer dans Odoo 19.
